# TinyTile 

## what is TinyTile?

TinyTile is a lightweight suckless wayland compositor written in C with wlroots as a backend. TinyTiles goal is to be as lightweight and simple as possible, it doesnt have any flashiness, its made completely from scratch, and it is very very low on ram usage.


## How do i configure TinyTile?

TinyTile is configured from config.h its a entire config file made in C to be simpler, it edits keybinds and more, it edits auto starts, ui elements, colors, and etc, its your config for the window manager.

## Why should i use TinyTile?

TinyTile is ment to be minimal, if you do not want eyecandy the window manager isnt for you, TinyTile is made for lower end computers and people wanting more minimalism. it does'nt have blur or anything fancy. its overall simple
